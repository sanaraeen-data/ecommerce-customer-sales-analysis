# E-Commerce Customer & Sales Analysis

## 📌 Project Overview

This project analyzes e-commerce sales and customer data to identify sales trends, customer purchasing behavior, profitability, and high-value customers.

The analysis was performed using SQL, and the results were presented through an interactive Power BI dashboard.

## 🛠️ Tools & Technologies

- SQL
- Power BI
- Excel
- Data Analysis
- Data Visualization

## 🎯 Business Objectives

The main objectives of this project are:

- Analyze overall sales and profit performance
- Identify top-performing customers
- Analyze new vs repeat customers
- Identify high-value customers
- Analyze customer order frequency
- Analyze regional sales performance
- Analyze monthly sales trends
- Measure Month-over-Month (MoM) sales growth
- Analyze product and category performance

## 🔍 SQL Analysis

SQL was used to perform:

- Data exploration
- Aggregation and grouping
- Customer-level analysis
- Sales and profit analysis
- Customer segmentation
- Top customer analysis
- Regional analysis
- Monthly sales analysis
- Month-over-Month analysis
- Advanced analytical queries using CTEs, subqueries, joins, CASE statements and window functions

## 📊 Power BI Dashboard

An interactive Power BI dashboard was created to visualize:

- Total Sales
- Total Profit
- Total Orders
- Total Customers
- Monthly Sales Trends
- Category Performance
- Regional Performance
- Customer Analysis
- Profitability

## 💡 Key Insights

The analysis helps identify:

- High-value customers contributing significantly to revenue
- Sales trends across different months
- Strong and weak-performing regions
- Customer purchasing patterns
- Product and category performance
- Changes in sales performance over time

## 📈 Business Recommendations

Based on the analysis, businesses can:

- Focus on retaining high-value customers
- Develop strategies to increase repeat purchases
- Target high-performing regions
- Improve underperforming product categories
- Monitor monthly sales trends to identify growth opportunities
